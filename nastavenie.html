Spoločné heslo pre 40 dní modlitieb

Tu si vytvoríte šifrovaný súbor data/auth.json. Návštevníci budú neskôr písať len spoločné heslo, nie GitHub účet ani token.

Táto stránka nič neposiela na internet. Token sa zašifruje priamo vo vašom prehliadači. Vygenerovaný súbor vložíte do rovnakého GitHub repozitára ako web.

1. Pripravte si GitHub token

Na GitHub → Fine-grained personal access token vyberte Only select repositories, označte len tento repozitár a v Repository permissions nastavte Contents → Read and write. Nastavte krátku platnosť, napríklad do 31. 12. 2026.

Na GitHube otvorte data/auth.json, kliknite na ceruzku Edit file, nahraďte celý obsah výsledným JSON a potvrďte Commit changes. Alebo nahrajte stiahnutý súbor do priečinka data ako náhradu existujúceho.

Potom otvorte hlavnú stránku, vyberte deň, zadajte meno a svoje heslo. Pri správnom nastavení sa meno uloží do data/records.json.

Dôležité: ktokoľvek, kto získa spoločné heslo, dokáže v prehliadači získať aj oprávnenie tokenu a meniť obsah daného repozitára. Nepoužívajte rovnaké heslo inde, neukladajte token otvorene do kódu a po skončení projektu ho na GitHube zrušte. Mená zostávajú verejne čitateľné.

Na jednoduché dočasné použitie, nie na citlivé osobné údaje alebo silnú bezpečnosť. Zmena hesla sa vykoná opakovaním tohto postupu.
